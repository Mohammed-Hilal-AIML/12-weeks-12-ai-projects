# Outputs

Generated results are stored here.

Expected output areas:

```text
outputs/
├── image_detection/
├── video/
│   ├── annotated_video.mp4
│   ├── object_counts_over_time.csv
│   └── counts_over_time.png
├── training/
└── custom_predictions/
```

The exact files depend on which scripts you run.

Large videos, plots, and trained models are ignored by Git by default.
