
# Week 1: SMS Spam Classification System 📱🤖

> **12 Weeks, 12 AI Projects Challenge** — Project #1

A machine learning and natural language processing (NLP) project designed to classify SMS messages as either **Spam** or **Ham (Legitimate)**. This project builds a text classification pipeline from scratch, covering text preprocessing, tokenization, feature extraction via TF-IDF, and model training using classic machine learning classifiers.

---

## 🚀 Features

* **Text Preprocessing & Cleaning**: Lowercasing, punctuation removal, stopword filtering, and stemming/lemmatization.
* **Feature Extraction**: Converting raw text into numerical feature vectors using Term Frequency-Inverse Document Frequency (TF-IDF).
* **Model Training & Evaluation**: Training classifiers (such as Naive Bayes, Logistic Regression, or Support Vector Machines) and evaluating them using accuracy, precision, recall, and F1-score.
* **Interactive Inference**: A script or simple interface to classify custom SMS text inputs in real time.

---

## 🛠️ Tech Stack & Skills Learned

* **Language**: Python 3.10+
* **Libraries**: `scikit-learn`, `pandas`, `numpy`, `nltk` / `spaCy`
* **Skills Mastered**: Text vectorization, handling imbalanced datasets, model evaluation metrics, and building an end-to-end ML inference pipeline.
